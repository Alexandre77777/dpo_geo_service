## 📋 Описание

**GeoAnalytics Service** — интерактивный геоаналитический сервис, позволяющий оценивать обеспеченность территорий объектами городской инфраструктуры. Сервис автоматически загружает данные из OpenStreetMap, выполняет буферный анализ и визуализирует результаты на интерактивной карте.

### Что умеет сервис?

- 🔍 **Загрузка данных** — автоматическое получение объектов инфраструктуры из OpenStreetMap
- 🛡️ **Буферный анализ** — расчёт зон доступности для каждого типа объектов
- ⬡ **H3-индексация** — разбиение территории на гексагональную сетку Uber H3
- 📊 **Композитный индекс** — расчёт взвешенного показателя обеспеченности
- 🎨 **Визуализация** — интерактивная карта с цветовым кодированием результатов
- 📥 **Экспорт** — выгрузка результатов в формате GeoJSON

## 🚀 Быстрый старт

### Требования

- Установленный Python 3.9+
- VS Code/PyCharm

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/username/geo-service.git
cd geo-service

# Создание виртуального окружения (рекомендуется)
```

```bash
streamlit run app.py
```

Приложение будет доступно по адресу: **http://localhost:8501**

## 📖 Руководство пользователя

### Шаг 1: Выбор области анализа

На карте слева используйте инструменты рисования для выделения интересующей территории:
- 🔲 **Прямоугольник** — для простого выбора области
- 🔷 **Полигон** — для произвольной формы

### Шаг 2: Настройка параметров

В правой панели настройте:

| Параметр | Описание |
|----------|----------|
| **Разрешение H3** | Детализация сетки (7-10). Больше = мельче ячейки |
| **Слои** | Типы объектов для анализа |
| **Буферы** | Радиус зоны доступности для каждого слоя (м) |
| **Веса** | Приоритет слоя в итоговом индексе (-1 до 1) |

### Шаг 3: Запуск и результаты

1. Нажмите **«Запустить анализ»**
2. Дождитесь завершения (время зависит от размера области)
3. Изучите результаты на карте
4. При необходимости экспортируйте в GeoJSON

## ⚙️ Конфигурация слоёв

Предустановленные слои настраиваются в файле `tags_presets.json`:

```json
{
  "presets": [
    {
      "name": "Школы",
      "key": "amenity",
      "value": "school",
      "buffer": 1600
    },
    {
      "name": "Метро",
      "key": "railway",
      "value": "subway_entrance",
      "buffer": 1600
    }
  ]
}
```

### Параметры слоя

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | string | Отображаемое название |
| `key` | string | Ключ тега OpenStreetMap |
| `value` | string | Значение тега OpenStreetMap |
| `buffer` | int | Радиус буфера в метрах |

### Популярные теги OSM

| Объект | key | value |
|--------|-----|-------|
| Школы | amenity | school |
| Детские сады | amenity | kindergarten |
| Поликлиники | amenity | clinic |
| Больницы | amenity | hospital |
| Аптеки | amenity | pharmacy |
| Супермаркеты | shop | supermarket |
| Парки | leisure | park |
| Метро | railway | subway_entrance |
| Автобусные остановки | highway | bus_stop |
| Велодорожки | highway | cycleway |

> 📚 Полный список тегов: [OSM Map Features](https://wiki.openstreetmap.org/wiki/Map_features)

## 📊 Методология

### Буферный анализ

Для каждой ячейки H3 создаётся буферная зона заданного радиуса. Объекты, пересекающиеся с буфером, учитываются в расчёте:

- **Точечные объекты** → количество
- **Линейные объекты** → суммарная длина (м)
- **Площадные объекты** → суммарная площадь (м²)

### Нормализация

Все показатели приводятся к диапазону [0, 1] методом Min-Max:

```
x_norm = (x - x_min) / (x_max - x_min)
```

### Композитный индекс

Итоговый индекс рассчитывается как взвешенная сумма нормализованных показателей:

```
index = Σ (weight_i × value_i) / Σ weight_i
```

## 🔧 API бэкенда

### `load_presets(filepath)`

Загружает конфигурацию слоёв из JSON-файла.

```python
presets = load_presets("tags_presets.json")
```

### `run_analysis(bbox, tags_config, weights, h3_resolution)`

Выполняет полный цикл геоанализа.

```python
results, osm_data = run_analysis(
    bbox=[37.5, 55.7, 37.7, 55.8],  # [west, south, east, north]
    tags_config=presets,
    weights={"Школы": 0.5, "Метро": 0.3},
    h3_resolution=9
)
```

**Возвращает:**
- `results` — GeoDataFrame с ячейками H3 и рассчитанными индексами
- `osm_data` — словарь с исходными данными OSM

## 🐛 Известные ограничения

- Зависимость от доступности Overpass API
